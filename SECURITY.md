# Security Policy

## Supported Versions

This project tracks a single Fess version at a time (see `pom.xml`'s parent
version and the [README](README.md#requirements)) — only the latest
[release](../../releases) is supported. There's no back-porting of fixes to
older releases.

## Reporting a Vulnerability

Please **don't** open a public issue for a security vulnerability. Instead,
use GitHub's private reporting for this repo:
[Security → Report a vulnerability](../../security/advisories/new).

This is a small, solo-maintained plugin, so there's no formal SLA — but
security reports get priority over everything else, and you'll get an
acknowledgement as soon as it's seen. Once a fix is available, it'll ship as
a new [release](../../releases) and the advisory will credit the report
(unless you'd rather stay anonymous).
